PORTFOLIO CÁ NHÂN – BẢN DỄ HIỂU

Cách chạy:
1. Giải nén file ZIP.
2. Mở index.html bằng Chrome hoặc dùng Live Server trong VS Code.

Bạn chỉ cần đọc 2 file:
- index.html = nội dung của website: tên, kỹ năng, dự án, Gmail, Facebook...
- style.css = giao diện: màu, bố cục, kích thước, cách hiển thị điện thoại.

Đã giữ thông tin bạn điền từ file ZIP gửi lên.
Đã xóa phần liên kết website nhóm khỏi portfolio cá nhân.
